# Mój CRM

Prosta polska wersja demonstracyjna CRM dla małej firmy.

## Publikacja przez GitHub Pages
1. Otwórz **Settings** repozytorium.
2. Wybierz **Pages** w menu po lewej.
3. W sekcji **Build and deployment** ustaw **Deploy from a branch**.
4. Wybierz branch **main** oraz folder **/(root)** i kliknij **Save**.
5. Po zakończeniu publikacji GitHub pokaże adres strony w tej samej sekcji.

## Ważne
To prototyp statyczny. Dane klientów i przypomnienia są przechowywane wyłącznie w localStorage tej przeglądarki i tego urządzenia. Nie ma logowania, wspólnej bazy, synchronizacji ani kopii zapasowych. Nie wpisuj prawdziwych danych poufnych ani wrażliwych.
